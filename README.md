# Road Lane Line Detection System Using AI

This project identifies road lane lines in driving videos using computer vision.

## Features
- Uses OpenCV for lane detection
- Streamlit interface for demo and visualization
- Edge detection, masking, Hough Transform

## How to Run
1. Install dependencies:
2.Launch the Streamlit app:
3. Upload a road video to see detected lanes in real-time.

## Folder Structure
- `lane_detection.py`: Core processing
- `app.py`: Streamlit app
- `test_videos/`: Sample videos
- `output_videos/`: Output videos with lane overlays
